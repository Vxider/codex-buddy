uConsole RGB 灯柱硬件构建说明

用于 codex-buddy 的侧板单灯 RGB 状态指示器方案。目标是以最小改动在 uConsole 上实现稳定、可返修、可扩展的状态灯硬件。

设备：uConsole Core：CM5 方案：单颗 RGB LED + 灯柱 版本：V1 构建说明

1. 方案概览

推荐结构：1 x 3mm 共阴极雾面 RGB LED + 1 x 短灯柱 / 导光件 + 1 x 改造侧板 + 1 x 背部灯座。

这版做什么

  • 在 uConsole 扩展舱侧板上做一个单孔 RGB 灯柱状态灯。
  • 从主板 J3 GPIO 扩展口取 3 路 GPIO 和 1 路 GND。
  • 通过软件映射显示 online、running、attention、error 等状态。

为什么不做三颗分立 LED

  • 正面更整洁，只需一个出光窗口。
  • 背部结构更紧凑，更适合侧板净空。
  • RGB 更容易实现闪烁、呼吸和状态过渡。

3. GPIO 连接方案

推荐焊接点

优先使用 uConsole 主板 J3 40-pin GPIO 扩展口，不要直接焊 CM5 模组本体。

  • Pin 11 → GPIO17 → Red
  • Pin 13 → GPIO27 → Green
  • Pin 15 → GPIO22 → Blue
  • Pin 39 → GND

为什么选这三个 GPIO

  • 都是稳定的通用输出脚。
  • 不占用 GPIO0/1 和默认 I2C 主线。
  • 不依赖硬件 PWM，软件控制就够用。
  • 后续维护时容易记忆和复用。
GPIO17 ---- 470R ---- R 引脚
GPIO27 ---- 470R ---- G 引脚
GPIO22 ---- 470R ---- B 引脚

RGB LED 公共阴极 ---- GND

第一版建议统一使用 470R。等结构跑通后，再按亮度和平衡微调阻值。

4. 机械结构建议

第一版优先做 圆孔 + 短灯柱，不要一上来做长条导光件。这样最容易成功，也最容易返工。
项目 推荐值 说明
侧板开孔 3.2mm - 3.5mm 圆孔 适配 3mm 灯柱或 LED 前端空间
灯柱材料 2mm - 3mm 亚克力圆棒 透明度和加工性最好
灯柱外露高度 0.3mm - 1.0mm 可齐平，也可略微内凹以提升耐用性
混光腔 1mm - 3mm RGB LED 与灯柱之间预留距离，用于混光

7. 3D 打印灯座要求

灯座必须完成的功能

  • 固定 1 颗 RGB LED。
  • 固定 1 根灯柱或导光件。
  • 提供遮光腔，减少串色和漏光。
  • 留出焊脚、热缩管和排线转向空间。

建议结构

  • LED 定位孔一侧，灯柱定位孔一侧。
  • 中间保留 1 - 3mm 混光腔。
  • 外围加遮光壁。
  • 第一版用 3M 薄双面胶固定到侧板背面即可。

8. 构建步骤

  1. 基于 uConsole 侧板模型建立二次修改文件，先只做单个圆孔版本。
  2. 打印一版侧板验证件，确认孔位、螺丝位和壳体净空。
  3. 制作灯座，确认 RGB LED、灯柱和混光腔尺寸匹配。
  4. 将 3 颗 470R 电阻分别串联到 R/G/B 三路线上，套热缩管绝缘。
  5. 将 4 芯排线焊到 RGB LED：R、G、B 以及公共阴极 GND。
  6. 将排线另一端焊到 uConsole 主板 J3：Pin 11 / 13 / 15 / 39。
  7. 用 Kapton 胶带沿壳体边缘整理排线，避免与装配件和转轴干涉。
  8. 固定灯座和灯柱，先在开壳状态下做通电测试，再完成整机回装。

9. 上电测试

在线 / Idle：绿色常亮
Running：蓝色常亮
Running Bash：蓝色慢闪
Attention：黄色慢闪
Error：红色常亮
Offline：熄灭
如果首版只想验证硬件，不必一开始就做呼吸灯。先验证 3 路 GPIO 分别能稳定点亮 R/G/B 三个颜色即可。

10. 风险与规避

颜色不均匀

不要让 RGB LED 紧贴出光面，保留混光腔；优先选择雾面 RGB LED。

灯太亮

从 470R 起步。如果仍过亮，优先将红色升到 680R，再调其他颜色。

透明导光件漏光

灯座外围要做遮光壁，导光件和灯座间不要留过大缝隙。

首版结构过于复杂

第一版只做圆孔 + 短灯柱，不要直接上长条灯柱窗口。

不建议把线直接焊到 CM5 模组本体，也不建议从高密度显示或摄像头连接器偷线。这两种方式的返修成本都偏高。
